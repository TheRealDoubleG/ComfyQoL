# ComfyQoL Changelog

## 0.6 Beta – 04.10.2026
- Added optional chat timestamps.
- Added optional objective-tracker fading in combat with configurable opacity.
- Added optional Talking Head suppression when that frame exists in the client.
- Added configurable mouse-wheel camera zoom speed.
- Added optional automatic decline for guild and party invitations.
- Kept all new behavior disabled by default and guarded for WoW Forever API differences.

## 0.5 Beta – 04.10.2026
- Polished the options layout and removed the duplicated "Komfort" heading.
- Improved category spacing, checkbox alignment and tab selected-state behavior.

## 0.3 Beta – 28.09.2026
- Profile changes now immediately reapply active feature settings.

## 0.2 Beta – 28.09.2026
- Moved automatic poor-quality item selling to ComfyBag.
- Kept ComfyQoL focused on cross-system convenience features.

## 0.1 Beta – 28.09.2026
- Initial modular QoL addon for WoW Forever.
- Added category-based settings: Automation, Chat, Interface, Camera and Social.
- Added auto repair, guild repair option and auto-sell-junk.
- Added optional auto-resurrection and duel blocking.
- Added chat arrow-key editing.
- Added UI error/zone-text suppression.
- Added maximum camera distance control.
- Added Comfy Suite shared profile/settings/info framework and Blizzard AddOns settings registration.
